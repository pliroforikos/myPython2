# Python 2.7 ΕΠΑΛ

Περιβάλλον προγραμματισμού **Python 2.7** για τους μαθητές της Γ' τάξης του Τομέα Πληροφορικής των ΕΠΑΛ
(μάθημα «Προγραμματισμός Υπολογιστών»), εμπνευσμένο από τον [Thonny](https://thonny.org).
Ακολουθεί την ύλη των «Σημειώσεων Μαθητή» του μαθήματος (ΙΕΠ / ΙΤΥΕ «Διόφαντος», 2η έκδοση 2017).
**Δημιουργός:** Λέων Προκόπης, καθηγητής Πληροφορικής ΠΕ86

Ύλη και θέματα προηγούμενων ετών: [panellhnies.gr](https://panellhnies.gr/mathima/programmatismos-ypologiston).

## Τι προσφέρει

- **Σύγχρονος editor (Monaco, ο editor του VS Code)**:
  - χρώματα κώδικα όπως στο IDLE (και στο βιβλίο)·
  - αυτόματη εσοχή μετά από `:`·
  - autocomplete με ελληνικές περιγραφές και snippets (`for`, `while`, `def`, ανάγνωση αρχείου, Tkinter, sqlite)·
  - εύρεση/αντικατάσταση, πολλαπλοί κέρσορες, folding, minimap·
  - καρτέλες για πολλά αρχεία.
- **Shell κάτω, όπως στον Thonny**:
  - η έξοδος του προγράμματος, και η είσοδος (`raw_input`/`input`) γράφεται μέσα στη ροή·
  - μετά την εκτέλεση υπάρχει `>>>` με πρόσβαση στις μεταβλητές του προγράμματος και ιστορικό με ↑/↓.
- **Λάθη όπως στον Thonny**:
  - κόκκινο traceback με συνδέσμους που πηγαίνουν στη γραμμή·
  - η γραμμή του λάθους χρωματίζεται στον editor.
- **Βοηθός λαθών στα ελληνικά**:
  - εξηγεί τι σημαίνει το λάθος, προτείνει τι να δοκιμάσει ο μαθητής και δείχνει παράδειγμα «λάθος/σωστό»·
  - αναγνωρίζει τις συνηθισμένες παγίδες της Python 2: κείμενο σε `input()`, ελληνικά σε ονόματα μεταβλητών,
    `print(..., end="")` της Python 3, καμπύλα εισαγωγικά και παύλες από αντιγραφή PDF, `lista = lista.sort()`,
    `.push()` σε στοίβα κ.ά.
- **Ζωντανός έλεγχος σύνταξης**: τα λάθη σύνταξης υπογραμμίζονται καθώς γράφει ο μαθητής.
- **Πάνελ μεταβλητών** με τις τιμές και τους τύπους (και στα ελληνικά).
- **Ελληνικά χωρίς `# -*- coding -*-`**:
  - τα προγράμματα τρέχουν με cp1253, όπως το IDLE στα ελληνικά Windows, άρα `len('Αθήνα') == 5`·
  - τα προγράμματα με Tkinter τρέχουν αυτόματα με utf-8, ώστε τα ελληνικά να φαίνονται σωστά στα παράθυρα·
  - η δήλωση `coding`, όπου υπάρχει, γίνεται σεβαστή.
- **Παραδείγματα από το βιβλίο**: δυαδική αναζήτηση, ταξινομήσεις, στοίβα, ουρά, αρχεία, Tkinter, SQLite,
  και ένα πρόγραμμα με σκόπιμα λάθη για εξάσκηση με τον Βοηθό.

## Απαιτήσεις

- Windows 10/11.
- **Python 2.7** (π.χ. 2.7.18) εγκατεστημένη. Από προεπιλογή αναζητείται στο `C:\Python27\python.exe`.
  Άλλη διαδρομή ορίζεται από **Αρχείο → Ρυθμίσεις**.

## Εγκατάσταση στο εργαστήριο

Από τον φάκελο `dist/`:

- `Python2-EPAL-1.0.0-setup.exe`: εγκατάσταση για όλους τους χρήστες, με συντόμευση και άνοιγμα αρχείων `.py`.
- `Python2-EPAL-1.0.0-portable.exe`: ένα αρχείο που τρέχει χωρίς εγκατάσταση (π.χ. από USB).

Τα προγράμματα των μαθητών αποθηκεύονται από προεπιλογή στο `Έγγραφα\Python2`.

## Για προγραμματιστές

```
npm install
npm start          # εκκίνηση
npm test           # tests (Node + Python 2.7)
npm run dist       # δημιουργία installer και portable .exe
```

> Αν το `npm start` τρέχει μέσα από το τερματικό του VS Code και το Electron συμπεριφέρεται σαν Node,
> διάγραψε τη μεταβλητή περιβάλλοντος `ELECTRON_RUN_AS_NODE`.

| Αρχείο | Ρόλος |
|---|---|
| `backend/runner.py` | Εκτελεί το πρόγραμμα σε Python 2.7, πρωτόκολλο JSON-lines (έξοδος, είσοδος, λάθη, μεταβλητές, REPL) |
| `backend/checker.py` | Ζωντανός έλεγχος σύνταξης |
| `backend/_epal_util.py` | Κοινά: επιλογή κωδικοποίησης, compile χωρίς δήλωση coding |
| `src/main/` | Electron main: παράθυρο, μενού, αρχεία, διεργασίες Python |
| `src/renderer/editor.js` | Monaco: γλώσσα Python 2, θέματα IDLE, autocomplete, hovers |
| `src/renderer/shell.js` | Shell τύπου Thonny |
| `src/renderer/errorHelp.js` | Ο Βοηθός λαθών (κανόνες και ελληνικά κείμενα) |
| `src/renderer/pydocs.js` | Ελληνική τεκμηρίωση για autocomplete/hovers |
